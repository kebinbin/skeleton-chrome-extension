# Skeleton Layout playground

A route-free Vite + React page for manually testing Skeleton Layout against a realistic, production-style interface.

The page uses one shared 12-column container across its navigation, editorial hero, nested bento grid, semantic data table, and footer. It intentionally mixes Grid and Flexbox, varied image ratios, nested alignment, spacing, padding, and responsive rearrangement.

Run it from the repository root:

```sh
npm run playground:dev
```
