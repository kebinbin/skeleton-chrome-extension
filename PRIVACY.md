# Privacy policy for Skeleton Layout

Last updated: July 13, 2026

Skeleton Layout does not collect, transmit, sell, or share personal information, browsing history, authentication information, website content, or analytics.

## Data stored by the extension

The extension stores only:

- Visualization preferences, such as palette mode, outline treatment, and override choices. These values use Chrome's synchronized extension storage and may be synchronized by Chrome when the user has browser sync enabled.
- The numeric IDs of tabs where the visualization is currently enabled, together with the generated CSS required to remove it. This information uses Chrome's in-memory session storage and is discarded when the browser session ends.

The extension does not store page URLs or page contents.

## Site access

Site access is temporary and begins only when the user invokes the extension from its toolbar action. Access is used to insert or remove visualization CSS in the selected tab. When optional diagnostics are enabled, the extension compares element dimensions locally and draws overflow markers or hover details in isolated overlays. Measurements and page content are not stored or transmitted. Skeleton Layout does not make network requests.

## Third parties

Skeleton Layout has no analytics SDKs, advertising SDKs, remote code, external services, or third-party data processors. Chrome may synchronize extension preferences according to the user's browser and Google Account settings; that processing is governed by Google's policies.

## Changes

Material changes to this policy will be documented in the extension's release notes and reflected by the date above.
